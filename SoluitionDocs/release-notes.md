DataByte for SSMS 2026.11.6.1357

New
- ScriptCast (SQLExtended > ScriptCast). Run the query window's script, or its selection, on many databases at once, across every server connected in Object Explorer. Tick the databases (with Select All, a name filter and a hide-system-databases option), click Cast, and each database runs in parallel on its own connection. The results merge into one grid per result set with ServerName and DatabaseName first; a database whose columns don't match gets its own flagged tab. Each database's messages, errors and rows affected are shown, with a summary. `GO` batches work as they do in a query window. Thanks to @walterstypula for the idea and the detailed spec (#13).
- Cast Lists. Save the ticked databases as a plain JSON file, load one (a network share works, so a team can share them), and open it in an SSMS tab to edit by hand; saving reloads it. A bad entry is flagged without stopping the rest of the list loading, servers that aren't connected show with a Connect button, and a Cast List never holds credentials.
- ScriptCast transaction mode. Tick Run in transaction and each database's changes stay uncommitted until you click Commit All (enabled only when every database succeeded) or Rollback All. Rows affected per database are shown before you commit. With Auto rollback (on by default), one failure rolls back every database. Open transactions roll back by themselves after a timeout (300 seconds by default, Settings > ScriptCast, or change it for one cast). Scripts with their own BEGIN TRAN, COMMIT or ROLLBACK are refused in this mode. Commits run one database after another, so if a connection drops partway through, the Summary says exactly which databases committed.
- ScriptCast asks before running a script that changes data or schema when Select All was used, and applies the UPDATE/DELETE-without-WHERE check to every cast.
- Schema Compare (SQLExtended > Schema Compare). Compare two schemas side by side: folder exports, database projects or live databases. Choose what to ignore, see each object's differences, and generate a change script.

Fixed
- IntelliSense: Space could replace a word you had already finished with a suggestion that only contained it, so `DELETE FROM` followed by Space became `DELETE DATEFROMPARTS`. Space now only accepts a suggestion that starts with what you typed, and never replaces a complete keyword such as `IS`, `IN` or `AS`. Thanks to @walterstypula for the report (#11).
